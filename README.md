# ZZZombeMod
Мод для Among Us: добавляет мини-игры с подсветкой ролей и Зомби-режим с заражением через касание.

Данный мод добавляет возможность играть в зомби режим и мини игры,
Мини игры: просто окрашывают предателя в красный и мирных в голубой,
Зомби режим: предатель становится нулевым пациентом, через некоторое время он превращается в зомби и заражает через касание, автоматическая победа когда все станут зелеными, так же можно настроить дистанцию 
заражения.
В моде так же есть пару нюансов например преды могут убивать и саботировать.
